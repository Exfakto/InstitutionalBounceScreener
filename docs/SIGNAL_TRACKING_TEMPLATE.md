## Outcome Guidance

Use consistent outcome notes so weekly review is easier:

- `Hit target`
- `Held above support`
- `Support failed`
- `Stopped out`
- `Still active`
- `No follow-through`
- `Data issue`

## Measurement Notes

- Max drawdown should be measured from the reviewed current price or planned entry, whichever was used for the trade idea.
- Max favorable move should be measured from the same baseline.
- If the signal was not actionable because data was missing, mark the outcome as `Data issue` and explain in notes.
- If the candidate was reviewed but not tracked as a trade idea, do not add it here; keep it in the feedback log instead.
